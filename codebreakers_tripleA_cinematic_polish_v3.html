HOW TO PLAY

  1. Choose a world and mission. All levels are open. Completed levels are marked SOLVED.
  2. Clear the security checkpoint. Answer the question to unlock the mission's goal.
  3. Plan your route. Multiple paths can lead to the end. Watch obstacles, keys, switches and portals.
  4. Program your agent. Use direction buttons or the code editor with move commands, loops and if/else.
  5. Run and debug. Follow the movement trail and read collision messages if blocked.
  6. Reach the goal. Earn XP and mark the mission as SOLVED.

Tip: The editor supports a limited JavaScript-style learning language, not arbitrary JavaScript.
